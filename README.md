# Diabetes Prediction Pipeline

A Machine Learning web application that predicts whether a person is likely to have diabetes based on medical input parameters.  
This project demonstrates an end-to-end ML pipeline including data preprocessing, model training, serialization, and deployment using Python.

---

## Features

- Predicts diabetes using trained ML model
- User-friendly interface with Streamlit/Flask
- Trained model saved using Pickle
- Docker support for containerized deployment
- Easy to deploy and scale
- Clean and modular project structure

---

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit / Flask
- Pickle
- Docker
